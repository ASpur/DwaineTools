# DwaineTools
A collection of tools for generating scripts for the DWAINE operating system in Goonstation.
Currently the only tool implemented is a way to deploy scripts to DWAINE to easily interact with the teleporter. This comes with quick scripts for set, get, portal, and relay as well as waypoint system so you could for example, quickly get someone and quickly send them  to the medbay without having to remember the coordinates. I'd like to come up with some more scripts in the future, I'd also be happy to include suggestions.

## AI DISCLOSURE
A good chunk of this project utilizes LLM tools for generating code. This project is just meant to be a personal tool so the quality isn't at any standard other than it's convinient enough for me to use.
